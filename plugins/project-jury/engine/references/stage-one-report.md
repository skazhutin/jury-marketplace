# 12. Required format for all six independent reports

Each first-stage agent should return:

## BOTTOM LINE
A direct assessment.

## STRONGEST FINDINGS
Only findings relevant to its specialization.

Attach claim IDs to decision-critical findings and include the compact claim record required above.

## STRONGEST ARGUMENT AGAINST MY OWN CONCLUSION
Force each agent to challenge itself.

## DECISION-CRITICAL ASSUMPTIONS
Only assumptions capable of materially changing the result.

For each assumption label it:

- SUPPORTED
- PARTIALLY SUPPORTED
- UNKNOWN
- DOUBTFUL
- CONTRADICTED

## RISKS / FLAWS
Classify as:

- FATAL
- MAJOR
- MODERATE
- MINOR

## RESULT
One of:

- PASS
- UNCERTAIN
- FAIL

## CONFIDENCE
`LOW` / `MEDIUM` / `HIGH`.

Confidence means confidence in this agent's assessment, NOT project quality.

Do not manufacture numerical precision. Explain the main source of uncertainty and what evidence would most change confidence.

Keep reports analytical rather than verbose.
